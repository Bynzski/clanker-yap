# Clanker Yap v0.3.1

Linux x86_64 only. This release contains one AppImage and its SHA-256 checksum.

## Highlights

- Native Wayland push-to-talk shortcuts prevent the held hotkey from typing repeated characters into the focused terminal, including Hermes in Konsole.
- Shortcut editing on Wayland uses the desktop shortcut dialog and displays the desktop's actual binding.
- The portal client ships inside the AppImage. Supported desktops such as KDE need no helper package.
- X11 retains the existing shortcut backend.

## First launch

Close any older copy before opening this AppImage. On Wayland, approve or choose the “Hold to dictate” shortcut in the desktop dialog. Use the app's shortcut edit button to change it later.

## Validation

- Rust tests, Clippy with warnings denied, and formatting checks passed.
- Private D-Bus tests cover immediate portal responses and cancelled setup.
- The real KDE portal application registration and session creation/cleanup smoke test passed.
- Frontend shortcut configuration and settings event smoke checks passed.
- The v0.3.1 AppImage launched and registered the native Wayland `Alt+Q` shortcut on KDE, with the existing model path and settings.
- Built with `npm run release:verify`, using `NO_STRIP=1` and AppImage-only bundling.

## Known limitations

- Wayland requires a desktop implementing the GlobalShortcuts portal. There is no X11 shortcut fallback on Wayland because it can leak keystrokes into native windows.
- Shortcut setup can display a desktop authorization dialog; this is part of the native desktop integration.
- Interactive microphone, Hermes/editor paste, overlay appearance, and restart-persistence smoke checks have not been confirmed for this release. X11 desktop testing was not available in this Wayland session.
